# Repository Structure

```
data/                   CSV datasets + the data-generation notebook
  EEG/PSD/              real EEG spectra (PATHS study) + the notebook that computed them
  generate_datasets.ipynb   single source of truth for all three CSVs

python/                 Python case studies
  CaseStudy_1/           notebook + outputs/{figures,results}
  CaseStudy_2/           notebook + outputs/{figures,results}

r/                      R case studies
  case1/code/            CaseStudy_1.ipynb (R port) + outputs/
  case2/                 not started yet

matlab/                 not started yet

website/                this documentation site (MkDocs Material)

useful_materials/       exploratory notebooks and pseudocode that preceded
                        the main pipeline — not part of it, may be out of sync
```

Each case study's notebook and its `outputs/` folder live together, so the
figures and tables you see on each case study's page are generated by the
notebook right next to them — nothing is hand-copied.
