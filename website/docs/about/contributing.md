# Contributing

This tutorial is under active development. If you spot an error, have a
question, or want to help port a case study to R or Matlab, please open an
issue or pull request on
[GitHub](https://github.com/SanCamilloIRCCS-OndaLab/tutorial_EEG-NPSY).

There is no formal contribution process yet — just open an issue to
discuss what you have in mind before sending a larger pull request.
